# talog 빠른 사용법 (명령 정리)

talos 설비 로그 분석기입니다. **설치 불필요** — 압축을 아무 폴더에나 풀고
바로 실행하면 됩니다 (Python 필요 없음).

동봉 파일: `talog.exe`(본체) · `run_talog.bat`(드래그&드롭 실행기) ·
`USAGE.md`(상세 설명서) · `README.md`(이 파일)

---

## 1. 로그 폴더 1개(하루치) 분석

### 방법 A — 마우스만으로
날짜 폴더(예: `...\log\cmfb#1\01`)를 **`run_talog.bat` 위에 끌어다 놓기**
→ 레시피 경로를 물으면 입력하고, 없으면 그냥 Enter
→ 완료되면 리포트(HTML)가 자동으로 열립니다.

### 방법 B — 명령창(cmd)
```
talog.exe "H:\000. PJT\00. CTR\log\cmfb#1\01"
```

레시피가 있으면(권장 — 채널 이름 번역·정상 스킵 구분·GPU 배치 조인):
```
talog.exe "H:\000. PJT\00. CTR\log\cmfb#1\01" --recipe "H:\000. PJT\00. CTR\log\cmfb#1\CMFB"
```

완료 후 리포트를 자동으로 열려면 `--open` 추가:
```
talog.exe "H:\...\log\cmfb#1\01" --recipe "H:\...\CMFB" --open
```

### 결과물 위치
기본값: `<로그폴더>\talog_out\` 아래에 생성됩니다.

| 파일 | 내용 |
|---|---|
| `<태그>.html` | 인터랙티브 리포트 (다크/라이트, 브라우저로 열기) |
| `<태그>.sqlite` | 조회용 DB (이벤트·검사·채널 전체) |
| `<태그>_diagnosis.md` | 자동 진단 소견 텍스트 |

출력 위치를 바꾸려면:
```
talog.exe "H:\...\01" --out "D:\분석결과"
```

## 2. 로그 폴더 N개 분석

### 경우 ① 한 설비의 여러 날짜
날짜 폴더가 아니라 **설비 폴더를 통째로** 지정하면, 하위 날짜 폴더
(27, 28, 29, ...)를 전부 찾아 일자별 리포트를 만들고, 한 페이지에서
넘겨보는 `index.html`(추이 비교 포함)까지 자동 생성합니다.
```
talog.exe "H:\000. PJT\00. CTR\log\cmfb#1" --recipe "H:\...\CMFB"
```
드래그&드롭도 동일 — 설비 폴더를 bat 에 끌어다 놓으면 됩니다.

### 경우 ② 여러 설비를 한 번에 (fleet)
설비 폴더들이 모여 있는 루트를 `fleet` 명령으로 지정합니다.
```
talog.exe fleet "H:\000. PJT\00. CTR\log"
```
→ c1xx, cmfb#1, f150, ... 설비×일자 전부 분석 후
`talog_out\index.html` 통합 인덱스(설비별 추이·이상·NG 요약)가 열립니다.

빨리 돌리고 싶으면(대용량 종속성 그래프 로그 생략):
```
talog.exe fleet "H:\...\log" --fast
```

## 3. 주요 옵션 정리

| 옵션 | 설명 |
|---|---|
| `--recipe <폴더>` | 레시피 조인 (ALG.ini 가 있는 폴더 지정) |
| `--out <폴더>` | 결과물 출력 위치 (기본: 로그폴더\talog_out) |
| `--open` | 완료 후 리포트 자동 열기 |
| `--fast` | 대용량 그래프 로그 생략, 속도 우선 |
| `--llm` | 로컬 Ollama 로 AI 종합 소견 추가 (Ollama 설치 시) |
| `--detail N` | 간트 상세 내장 검사 수 (기본 60) |
| `--version` | 버전 확인 |

---

## 4. 자주 겪는 상황

- **네트워크 경로(H:, \\192.168.x.x)** 그대로 지정해도 됩니다.
- **경로에 공백**이 있으면 반드시 큰따옴표로 감싸십시오.
- 레시피 없이 돌려도 분석은 전부 됩니다 — 채널이 번호로만 나올 뿐입니다.
- 리포트 우상단 버튼으로 다크/라이트 전환, 상세 분석 탭에서
  검사 조회·간트·종속성 그래프·모델 분포·에러 원문·GPU 를 볼 수 있습니다.
- 오류 메시지가 나오면 화면 문구를 그대로 캡처해 전달해 주십시오.
