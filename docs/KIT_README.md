# talog 빠른 사용법

talog 는 설비 PC 에 상주하는 **AI 비전 로그 운영 플랫폼**입니다. **설치 불필요** — 압축을 아무
폴더에나 풀고 바로 실행하면 됩니다 (Python 필요 없음).

동봉 파일: `talog.exe`(본체) · `run_talog.bat`(실행기) · `run_service.bat`(화면 없는 상주) ·
`talog.yaml`(설정) · `USAGE.md`(상세 설명서)

## 1. 콘솔 — 더블클릭
`run_talog.bat` 을 **더블클릭**하면 브라우저에 콘솔(http://127.0.0.1:8778)이 열리고 감시가 시작됩니다.

| 화면 | 하는 일 |
|---|---|
| 운영 현황 | 수집 → 탐지 → 판단 → 알림 네 단계 상태, 오늘 사건·경보 |
| 사건 | 사건별 원인 판단(룰·LLM 일치 여부)·권고 조치·근거·보낸 메일, 사건에 질문 |
| 분석 | 로그 폴더 진단 리포트 · 경보 재현 · 리포트에 자연어 질문 |
| 설정 | 수집·탐지(경보 규칙)·판단(AI)·알림(메일) |

검은 창을 닫으면 감시도 멈춥니다.

## 2. 로그 폴더 하나를 리포트로 — 끌어놓기
로그 폴더(하루치 `...\2026_09\05`, 설비 폴더, 여러 설비를 가진 루트 모두 가능)를
`run_talog.bat` 위에 **끌어다 놓으면** 진단 리포트를 만들어 엽니다.

## 3. 명령줄
```
talog.exe                        콘솔
talog.exe run --check            설치 점검
talog.exe run                    화면 없이 상주
talog.exe analyze <로그 폴더> --recipe <레시피> --open
```

자세한 내용은 `USAGE.md` 를 보십시오.
