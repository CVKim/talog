분석할 원본 로그

Claude 가 이 폴더의 원본 로그를 시각·문구·검사 id 로 직접 찾아 읽습니다. Claude 에게는 경로 대신 '선택'으로만 알립니다.

데이터·비용

  • 추가 과금 없음 — 구독 로그인으로만 실행합니다. 이 PC 에 API 키가 있어도 빼고 띄웁니다. 구독 사용량에는 포함됩니다.
  • 마스킹 — 검사 id → ID-xxxxxx, 경로 → <로그>. 원본 로그 줄도 가려서 넘깁니다.
  • 읽기 위주 — talog 도구는 읽기만, 쓰기는 reports 폴더만. 명령 실행·설정 수정은 막힙니다.
  • 그래도 전송됩니다 — 읽은 내용은 Anthropic 으로 갑니다. 고객이 승인한 범위만 연결하십시오.
